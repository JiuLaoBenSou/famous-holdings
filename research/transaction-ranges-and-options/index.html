Amounts, dates and options: four fields that change a story.

Avoid false precision when turning an official transaction report into a post.

ON THIS PAGE01 / An amount range is not an exact trade value02 / There can be more than one relevant date03 / Options require their own units04 / A pre-publication checkOriginal references ↗

An amount range is not an exact trade value

If a report provides a lower and upper amount, display both endpoints. A midpoint may be useful in an explicitly hypothetical model, but it is not the disclosed transaction amount. It should not appear as an exact factual value in a headline or chart.

Keep an unknown value separate from zero. A missing quantity does not mean that no shares changed hands; it means the collected evidence does not state a supported quantity.

There can be more than one relevant date

Transaction date, notification date, filing date and the date this website collected the document describe different events. A newly collected old transaction does not become a new trade. Always select the date that matches the claim you are making.

Options require their own units

An option purchase, an exercise and a common-stock purchase should not share one unlabeled “shares bought” column. Preserve the instrument, the action and the quantity unit. Where a document supplies a conversion to underlying shares, retain that statement and its source rather than applying an assumed multiplier.

Do not treat the reported value of an institutional option exposure as its premium or use it to calculate an invented gain. A strike price and an expiration date also do not establish the price paid for the contract.

A pre-publication check

The original Pelosi filing is a useful reading example because it contains stock transactions and option-related entries. The website’s selected records should never be represented as a complete reconstruction of the family account.

  • Can a reader identify the owner without guessing?
  • Does the number mean shares, contracts, underlying exposure, value or a range?
  • Does the date identify the transaction or only its disclosure?
  • Does the source establish the claimed remaining balance or return? If not, remove that claim.
